## VIRTUAL ASSISTANCE TASK MANAGER

 * ### Create a dashboard that stores tasks from the user 
 * ### There are three(2) sections on the platform:
        1.  The section that contains the data for sales made
        2. The section that contains the expenses incured 
 
 * ### Deduct the total expenses incured  from the sales made
 * ### Store the balance as net if the expenses is lower than the sales
 * ### Store as deficit if the expenses exceeds the sales
